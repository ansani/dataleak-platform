What to do, in this order

The order is the important part. If malware is still running on the device, changing your passwords first simply hands the attacker the new ones as well.

  1. Clean the infected computer first, or isolate it, before using it for anything else. Until that is done, none of the steps below will hold.
  2. From a clean device, change the passwords for the exposed accounts, and for any other account where you reused the same password.
  3. Revoke active sessions, browser sync tokens, saved passwords, API keys and recovery methods. A stolen session cookie survives a password change; revoking it does not.
  4. Enable multi-factor authentication, preferably with an authenticator app or a hardware key rather than SMS.
  5. Review recent account activity — forwarding rules, recovery email, payment methods and connected devices. Attackers often leave a way back in.
  6. Expect phishing that references this leak. Now that the data is circulating, others will use it too, and some will pretend to be me.
  7. Never send passwords, identity documents, full logs or browser exports through public channels — not to me, not to anyone.
